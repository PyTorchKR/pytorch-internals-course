# Simple English(ASD-STE100) 2차 리뷰 2026-10-03 (Opus 리뷰 → Opus 검수, 미반영)

1차 리뷰(`../simple-english/`)는 강의당 40건 상한이 있어 빠진 문제가 있었다. 이 2차 리뷰는 1차가 다루지 않은 남은 문제를 찾는다. 1차 40개 항목이 다룬 문장, 1차 "용어 결정", 저자가 미반영·유지로 정한 항목은 다시 제기하지 않았다. 지침은 [PROMPT.md](PROMPT.md)이고, 규칙과 한국어 적용표(A~N)는 1차 [PROMPT.md](../simple-english/PROMPT.md)를 그대로 쓴다. **01·02강은 저자 결정대로 반영했다(아래 "반영 현황"). 03~07강은 findings만 있다.** 리뷰는 main 948262a에서 했다. 그 뒤 PR #59가 06강 bucketing 절에 그림 5개와 prefill·extend·decode 정의를 넣었으므로, 06.md는 PR #59 반영 후(674e327) 행 번호로 갱신하고 바뀐 항목(02·03·07·08·27)을 다시 확인했다. 그 뒤 PR #61(그림·위젯과 본문의 drift 수정)이 02·03·04강에 그림 설명 줄을 넣어 행이 밀렸으므로, 02·03·04.md의 행 번호를 PR #61 반영 후(deb1378) 기준으로 다시 맞췄다. PR #61은 06·07강에서는 같은 줄 안의 문구만 바꿨고, 2차 항목 중 원문이 바뀐 것은 06강 33번(112행 "왼쪽 그림처럼" → "아래 첫 번째 그림처럼") 하나다. 01·05·07.md는 행 번호 변화가 없다.

## 저자 판단이 필요한 것

- 1차 용어 표에 없던 새 혼용: 02강 바인딩/binding·entry point/진입점, 03강 캡처/capture·명령/명령어/instruction, 06강 배치/batch·프롬프트/prompt, 07강 architecture/chip. 1차에서 "결정 없음"으로 본 범주라 다시 다룰지 정해야 한다.
- 06강 bucketing 절의 표기(batch/prompt)를 본문(배치/프롬프트)에 맞출지.
- 리뷰어가 1차 매핑(E·F·L·B = high)과 달리 오독 위험이 낮은 B·F를 med로 내린 강의가 있다(01·03·04). 건수 비교 시 참고.
